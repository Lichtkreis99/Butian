# 步天 BuTian

> 网页显示名「步天」（取《步天歌》之意）；毕业设计选题名仍为「宣夜」，「宣夜」也是三种星空模式之一。

宣夜是一套离线天文可视化：把真实三维星空、浑天天球投影、盖天平面图，以及星盘、七政四余、
四柱八字的结构放在同一个界面中对照。

## 打开

先构建项目，然后直接双击 `dist/index.html`。成品不需要服务器或网络连接，Chrome 与 Safari 均可
通过 `file://` 使用。

## 三种模式

- **宣夜**：查看恒星的真实三维深度和太阳系实体。
- **浑天**：默认是从当前地点观察的天象仪内视；拖拽改变方位与高度，滚轮改变视场。
  设置中可选择球极、透视或等距鱼眼投影，并控制地面、大气与各类网格。「外视」保留原有
  天球机位、锁定、深度连线和解体演示。内视底部快捷栏可切换中国星官/西方星座、星座
  插图、纯色或 Guéreins 实景地景、大气、方位点和网格。
  恒星按视场与 Bortle 等级动态控制极限星等，近地平线应用大气消光、轻微红化和折射；银河
  HiPS 与深空天体标记共用三种天象仪投影。拖拽带惯性，滚轮在对数视场上平滑缩放。
- **盖天**：从地球视点朝向当日北天极，并打开等距方位投影的盖天图。

右侧有五个标签：观星、星盘、七政四余、四柱八字和盖天图。「观星」不显示盘面比较；其余
标签会声明式切换相关三维图层。盘面中的天体、宫头、轴点、宿和星官可与三维视图双向选择。

## 界面与对照

顶部集中时间、地点、三种模型切换、设置与关于。左上「视点」收纳宣夜预设或浑天机位；底部
图层工具栏在每种模式中保持固定，左下「显示范围」抽屉收纳行星与恒星范围，右下信息卡独立
滚动。右栏依次是标签、会自动换行的盘面工具栏、盘面和可折叠表格，不再使用互相遮挡的浮动框。

设置页只保留名称风格、标签密度、恒星亮度、投影方式、默认开关和星官层等低频偏好。图层栏
直接控制星座线、名称、插图、文化、行星名、轨道、投影线和网格；浑天内视另有地景、大气、
方位点、地平网格和赤道网格。设置和最后使用的标签页保存在本机；存储不可用时回退到默认值。

浑天视窗按 `/` 打开搜索，可用中英文星名、HIP、Bayer 名称、行星、Messier/NGC 编号和星官名。
空格回中所选目标，`T` 切换跟踪；方向键平移，PageUp/PageDown 与 `+`/`-` 缩放；`J/K/L`
控制时间减速、实时与加速，`8` 回到当前时间。底部时间栏与顶部历元保持同步；底部时间栏和
图层栏在三秒无边缘活动后自动隐藏。

光污染按 Bortle 1–9 设置，对应约 7.6–4.0 等的观测上限，并共同调节恒星、银河、深空天体和
夜空背景。关闭大气后同时关闭消光与天空辉光。星等较亮的恒星保留柔和光晕，所选目标用环形
标记；标签阈值随视场收放并以淡入淡出过渡。

「隐藏未涉及天体」按盘面上下文控制行星、轨道和恒星。行星可见度使用以当前中心天体为基准的
对数范围；恒星距离可用双滑块限制为 1–5000 pc 或无限范围。两者只更新已有对象的透明度或
GPU uniform，不重建星表缓冲。

星盘工具栏提供现代/古典、宫制和文字/符号。七政四余提供回归/恒星黄道、今宿、命宫算法、
身宫算法、真/平均交点和文字/符号；尚未实现的原始体系会列出但不可选。四柱八字提供性别和
真太阳时。盘面共用隐藏未涉及天体、同心圆对照和回到盘面朝向。

右侧盘面还呈现可核对的结构关系。现代星盘绘制相位线、三角相位格和实角、容许度、入相/
出相表；古典盘采用托勒密相位和引擎光体半径。七政四余列出 makeYaos 的逐项查法，并以 26
份 API 样本及 40 份新增可比样本建立 207 项格局条件目录。主表只显示通过调校与留出核对的
39 项；124 项置于折叠的「核对未过」，44 项明确标为「规则待考」。
四柱八字以中性关系类型配色绘制干支连线，并列出每柱神煞的实际查表依据。点击关系会高亮
相关天体或干支；这些内容只说明规则及本盘命中依据，不给出倾向判断或建议。

同心圆对照把涉及的天体沿地心
方向动画到盘面环半径，真实距离仍保留在信息卡中；关闭后返回真实位置。启用方向对齐时，
地心俯视会匹配盘面绘制方向。

## 重建与检查

```sh
npm run build-data
npm run build
npm run check
```

依赖已固定；离线环境中不要运行 `npm install`。

浏览器自测可在构建后的本地文件上运行：`#selftest=ping`、`layout`、`ground`、`charts`、
`drag` 和 `ui`。UI 全量测试可用 `&mode=xuanye|huntian-inner|huntian-outer|gaitian` 分块。
第九期天空测试为 `#selftest=sky`，可用 `&part=labels|stars|extinction|inertia|zoom|search|deep-sky`
分块。

## 数据与许可

- 恒星：ESA Gaia DR3，经 Gaia Sky 整理；缺失的星官成员由 Stellarium 星表补齐。
- 中国星官：Stellarium Chinese skyculture，GPL-2.0+。
- 西方星座连线与插图：Stellarium Western skyculture，GNU GPL v2.0；由 Stellarium's team
  制作，Susanne M Hoffmann 与 Stellarium's team 重制。
- Guéreins 实景地景：Stellarium landscape HiPS；法国索恩河谷 Guéreins。
- 银河：Stellarium Milky Way HiPS，基于 Stellarium 银河纹理。
- 深空天体：Stellarium Mobile base DSO survey（2020-02-05）。
- 行星历算：astronomy-engine 2.1.19，MIT License。
- 行星纹理：Gaia Sky（ESA / Gaia Sky data team）及纹理各原始来源。金星表面图由 Praesepe
  提供，CC-BY-NC；金星云图改编自 NASA/JPL/Seal，CC-BY-NC。

本应用只呈现天文、历法结构与可复核的查表规则，不作命理推断。
